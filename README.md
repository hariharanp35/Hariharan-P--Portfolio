# Alex Morgan Portfolio

A premium, responsive React + TypeScript portfolio for a technology professional working across data, AI, code, and design.

## Features

- Responsive single-page layout with mobile navigation
- Dark/light theme persisted in localStorage
- Framer Motion reveal and interaction animations
- Data-driven project filtering
- Accessible contact form with success state
- Scroll progress, reduced-motion support, lazy-loaded project imagery
- Vercel-ready Vite build

## Install

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Customize

Edit the content in `src/App.tsx` and update the project array, skills, title, and bio. Set the contact and social links in a local `.env` file using `.env.example` as a template. Replace the remote Unsplash images with local WebP/AVIF assets when deploying. Add a real resume PDF or integration before publishing.

## Deployment

Deploy the repository to Vercel or Netlify using the default Vite settings. Build command: `npm run build`. Output directory: `dist`.
